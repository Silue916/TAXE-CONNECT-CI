# TaxeConnect - Roles et Permissions

## 1. Administrateur Systeme
- Rôle: supervision technique de la plateforme.
- Droits:
  - gerer les communes
  - creer les comptes mairies
  - gerer les parametres globaux
  - superviser la securite
  - acceder aux logs
- Limites:
  - ne modifie pas les montants legaux des taxes
  - ne valide pas les paiements fiscaux

## 2. Administration Communale
- Rôle: autorite fiscale locale.
- Droits:
  - enregistrer les commercants
  - definir les taxes communales selon deliberation
  - consulter les paiements
  - valider certains paiements
  - generer des rapports officiels
- Responsabilites:
  - conformite des montants
  - authenticite des recus
  - supervision du recouvrement

## 3. Agent Communal
- Rôle: operationnel terrain.
- Droits:
  - enregistrer des magasins
  - consulter les dettes
  - assister les commercants
  - verifier les paiements
  - signaler les impayes
- Restrictions:
  - ne modifie pas les regles fiscales
  - ne supprime pas les paiements

## 4. Commercant
- Rôle: contribuable final.
- Droits:
  - creer et consulter son compte
  - voir ses taxes dues
  - payer ses taxes
  - telecharger ses recus
  - consulter son historique
- Obligations:
  - fournir des informations exactes
  - respecter les echeances
  - conserver les preuves de paiement
